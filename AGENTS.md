# Project AI Instructions

For any frontend design, UI implementation, component work, styling change, responsive fix, accessibility pass, or frontend review, use the project skills at `.codex/skills/fresh-citrus-brand-guidelines` and `.codex/skills/ai-agent-frontend-rules`.

The branding skill requires reading `.codex/skills/fresh-citrus-brand-guidelines/references/brand-guideline.md` before designing or coding branded frontend UI. Treat it as the project source of truth for the Fresh Citrus AI Wellness identity, color tokens, typography, imagery, nutrition-specific UI, and brand tone.

The frontend rule skill requires reading `.codex/skills/ai-agent-frontend-rules/references/frontend-rulebook.md` before designing or coding frontend UI. Treat that rulebook as the project source of truth for AI Agent product UX, design system decisions, UI states, accessibility, performance, and final QA.

Do not build frontend screens as generic chatbot pages, decorative landing pages, or random SaaS templates. Build from design tokens, reusable components, clear page structure, explicit AI states, responsive behavior, and the final QA checklist in the rulebook.
